The circuit examples use Python's standard library. The current test suite has 38 passing cases. Calculated responses are ideal-model results; they are not hardware measurements.

## Engineering subjects

- Circuits and electronics: resistor loading, AC networks, electromagnetic fields, and transistor small-signal models.
- Digital systems: Boolean logic, adders, and state-based reasoning.
- Software: object-oriented models, algorithms, data structures, and numerical calculations.
- Foundations: calculus, linear algebra, differential equations, physics, and materials.
- Engineering practice: requirements, technical communication, economics, and ethics.

These examples were prepared for the portfolio and are distinct from submitted course assignments. Course notes describe subjects studied and do not state degree completion.
